# מנהל מדיה אישי — תוסף Chrome

תוסף Chrome בעברית הכולל:
- הודעה קטנה כשנכנסים לדף סרטון ב־YouTube.
- העתקת קישור הסרטון בלחיצה.
- הורדת קובצי וידאו או שמע מקישור HTTP/HTTPS ישיר, כאשר יש לך הרשאה להוריד אותם.
- בחירת תיקיית משנה בתוך תיקיית Downloads.
- אפשרות לפתוח חלון Save As בכל הורדה.
- הפעלה או כיבוי של ההודעה בדפי YouTube.

## חשוב לדעת

התוסף **אינו מוריד סרטוני YouTube או את זרמי השמע שלהם**, אינו עוקף הגבלות של האתר ואינו מציע איכויות שאינן זמינות בקובץ המקור. בדף YouTube מוצגת הודעה שמפנה לאפשרויות הרשמיות של האתר, אם הן זמינות למשתמש.

ההורדה מתוך חלון התוסף מיועדת לקובצי מדיה ישירים בלבד, למשל קובצי MP4 או MP3 שמאוחסנים באתר שבבעלותך או שקיבלת הרשאה להוריד. אין בתוסף המרת פורמטים או שינוי איכות.

## התקנה ידנית ב־Chrome

1. פתח את המאגר ב־GitHub ולחץ על **Code → Download ZIP**.
2. חלץ את קובץ ה־ZIP לתיקייה במחשב.
3. פתח Chrome ועבור אל `chrome://extensions`.
4. הפעל **מצב מפתח** (Developer mode).
5. לחץ על **טעינת תוסף שלא נארז** (Load unpacked).
6. בחר את התיקייה שחילצת, שבה נמצא `manifest.json`.
7. הצמד את התוסף לסרגל הכלים דרך סמל הפאזל.

## שימוש

- בדף סרטון ב־YouTube תופיע הודעה עם אפשרות להעתיק את הקישור או לסגור אותה.
- להורדת קובץ מורשה, פתח את התוסף, הדבק קישור ישיר לקובץ כגון `https://example.com/media.mp4`, בחר וידאו או שמע והתחל הורדה.
- כדי לשנות תיקיית משנה או את חלון השמירה, פתח את ההגדרות.

## תיקיית שמירה

Chrome מאפשר לתוסף לציין תיקייה יחסית בתוך תיקיית Downloads, אך לא לבחור בשקט כל נתיב מוחלט במחשב. אפשר להפעיל את האפשרות Save As כדי לבחור מיקום בכל הורדה.

## פרטיות והרשאות

- ההגדרות נשמרות מקומית באמצעות `chrome.storage.local`.
- לא נשלחים נתונים לשרת חיצוני ואין מערכת מעקב.
- הרשאת גישה לאתר המקור מתבקשת רק כשמתחילים הורדת קובץ ישיר מאותו אתר.
- ההורדה מתבצעת באמצעות Chrome Downloads API.

## בדיקות ידניות מומלצות

- פתיחת סרטון YouTube והצגת ההודעה.
- העתקת הקישור וסגירת ההודעה.
- כיבוי ההודעה בהגדרות ובדיקת התנהגותה.
- הורדת קובץ MP4 ישיר וקובץ MP3 ישיר שיש הרשאה להוריד.
- בדיקת סירוב לקישור YouTube ולקישור שאינו קובץ מדיה.
- בדיקת תיקיית משנה והאפשרות Save As.
